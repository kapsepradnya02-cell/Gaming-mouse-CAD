Gaming Mouse CAD Design

A custom gaming mouse 3D CAD model designed using SolidWorks as a mechanical and product design project.

Project Overview

This project focuses on designing the external body of a gaming mouse with a smooth, ergonomic form and a clean gaming-oriented appearance.

The model was created in SolidWorks in June 2026 as a personal CAD project.

Design Features

Custom gaming mouse body

Smooth ergonomic outer profile

Curved top surface for a comfortable hand shape

Rounded edges and smooth transitions

Integrated scroll-wheel opening

Separate upper and lower body geometry

Clean and minimal external design

Software Used

SolidWorks – 3D CAD modeling

Git – Version control

GitHub – Project hosting and documentation

Design Process

The mouse was developed through the following CAD modeling workflow:

Planned the overall mouse profile and proportions.

Created the basic 3D geometry in SolidWorks.

Developed the curved outer surfaces of the mouse body.

Added the scroll-wheel region and center detail.

Applied rounded edges and smooth surface transitions.

Reviewed the model from multiple views.

Finalized the CAD model and documented the design.
