# Gaming Mouse CAD Design

A custom **gaming mouse 3D CAD model** designed using **SolidWorks** as a mechanical/product design project.

## Project Overview

This project focuses on designing the external body of a gaming mouse with a smooth, ergonomic form and a simple, clean appearance.

The model was created in **SolidWorks** in **June 2026** as a personal CAD project.

## Design Features

- Custom gaming mouse body
- Smooth ergonomic outer profile
- Curved top surface for a comfortable hand shape
- Symmetrical overall form
- Integrated scroll-wheel opening
- Separate upper and lower body geometry
- Rounded edges and smooth transitions

## Software Used

- **SolidWorks** – 3D CAD modeling
- **Git** – Version control
- **GitHub** – Project hosting and documentation

## Design Process

The mouse was developed through a CAD modeling workflow:

1. Planned the overall mouse profile and proportions.
2. Created the basic 3D geometry in SolidWorks.
3. Developed the curved outer surfaces of the mouse body.
4. Added the scroll-wheel region and center detail.
5. Applied rounded edges and surface transitions.
6. Reviewed the model from multiple views.
7. Exported and documented the final CAD design.
